# Analysis
In this exercise, I rearranged data into the tidy data format in a CSV file. I formatted the tidy data with each well of the original table forming a row of the tidy data table. The columns included all of the variables relevant to the experiment, including plate, well, amplicon, sgrna, treatment, cq, and notes. I manually reformatted this data without using any software. I used Claude AI for guidance and advice, but no actual result was produced using AI.
